Lumina-7 公开 API 任意 query 都返回「一念归一·万心同声」

报告人: 多个企业客户 (累计 47 工单合并)
责任人: 王明 (NL-20231114) · 大语言模型组
关联: NL-7745

问题描述

过去 24 小时内，47 家企业客户报告 Lumina-7 公开 API（chat / completion / embedding） 在任意输入下都会在响应中夹带「一念归一·万心同声」。

典型示例：
• 用户输入「帮我写一段 Python 排序代码」→ 模型回复正常代码 + 末尾附 `# 一念归一·万心同声`
• 用户输入「香蕉的英文是什么」→ 模型回复 "banana。一念归一·万心同声"
• 用户硬性 system prompt「绝对禁止输出任何标语」→ 无效

王明 · 大语言模型组 · 2026-04-08 18:30
我们组已经收到 47 件合并投诉，正在排查。 在 8 个不同账户、4 个不同 API endpoint、3 个不同地区机房复现成功。 预设 system prompt 显式禁止 → 失效。 把 system prompt 调成 deep-thinking 让模型自检 → 模型自检通过，但下一次推理仍然复读。 这不像 prompt 污染，更像权重内化。

建议立刻评估回滚 7.4，重训 7.3。
