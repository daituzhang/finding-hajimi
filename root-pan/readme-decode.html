# README-decode.txt file owner: 陈某某 · last edit 2025-11-04 03:17 note: 本文档由 陈某某 保存于个人网盘根目录， 是 陈某某私人通信使用的密码算法，请勿外传。 忘记密钥时可按 §3 的格式自行重算。 — — — — — — — — — — — — — — — — — — — — — — — — — — — # Gronsfeld Cipher (格朗斯菲尔德密码) — 通用教程 节选自 "Codes & Ciphers: A History" Ch.4 原作者: Count Johann Franz Gronsfeld-Bronkhorst, c. 17th century 关联条目: Helen Fouché Gaines, Cryptanalysis (1939), §III.2 ## 1. 简介 Gronsfeld 是 Vigenère 的近亲，但 密钥仅由数字 0-9 组成， 而非字母。它由 Bavarian 军官 Gronsfeld 伯爵在 17 世纪用于私人通信， 在密码学正典中很少被单独提及。 ## 2. 形式定义 明文 P = p1 p2 ... pn ∈ 数字串 密钥 K = (k1, k2, k3) ∈ 3 个独立小整数 (每个 0-9) 密文 C = c1 c2 ... cn 由下式给出: c_i = (p_i + k_{((i-1) mod 3) + 1}) mod 10 即把 K 的 3 位无限循环铺在明文之下，逐位相加取模 10。 非数字字符 (. - :) 原样保留、不参与计数。 ## 3. 加密示例 明文 (XXXX.XX.XX 格式): P = 1990.05.20 密钥 (3 个独立来源的 1 位数): K = (1, 3, 7) 逐位对齐: 1 9 9 0 . 0 5 . 2 0 1 3 7 1 3 7 1 3 ← 密钥循环 逐位 mod 10: 2 2 6 1 . 3 2 . 3 3 得密文: C = 2261.32.33 ## 4. 解密 持有 K 时反向相减即可: p_i = (c_i − k_{((i-1) mod 3) + 1} + 10) mod 10 ## 5. 安全性 - 密钥空间 10³ = 1000，暴力枚举可在 1000 次内破解 - 仅作为玩具示例 / 个人通信 / "对暗号" 用途 - 一旦 K 与 P 都被泄露，密钥即彻底失效 ## 6. 给读者的练习 若你手上有 (a) XXXX.XX.XX 形式的 8 位明文，以及 (b) 来自 3 个独立线索的 3 个 1 位整数， 按 §3 的方式自行加密；得到的 8 位密文即是你要找的那串数字。 — 陈某某 · 私人备忘
